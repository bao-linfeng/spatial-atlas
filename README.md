# 苏南智城科技产业园 · 三维空间

「空间档案 · SPATIAL ATLAS」系列 02：一个在浏览器里看的苏南智城科技产业园三维动画沙盘。场景包括园区区位、塔楼、中轴、风车式排布的独栋和下沉广场，支持导览动画、夜景切换和视频录制。

> 江苏 · 常州 · 天宁 · 创客路 28 号
> 青洋高架以东、沪蓉高速以南、北塘河畔

## 运行

项目是纯静态页面，不需要安装依赖，也没有构建步骤。three.js（0.169.0）通过 importmap 从 npmmirror CDN 加载，所以打开页面时需要联网。

页面使用 ES Module，必须通过 HTTP 服务打开，直接双击 `index.html` 无法运行：

```bash
node server.mjs          # 默认端口 5191；指定端口：node server.mjs 8080
```

启动后访问 <http://127.0.0.1:5191/>。`server.mjs` 只用 Node 内置模块，不需要 `npm install`。

## 功能

| 按钮 | 说明 |
| --- | --- |
| 导览动画 | 按章节自动飞行讲解，再点一次中止 |
| 生长 | 楼宇从南入口开始依次升起 |
| 环绕 | 镜头绕场景自动旋转 |
| 夜景 | 在白天与夜晚之间渐变，夜晚有立面亮灯、路灯和车灯 |
| 标注 | 显示或隐藏建筑和道路标注 |
| 白模 | 切换为无贴图的白色体量 |
| 录制 | 播放一遍导览，同时导出 WebM 视频 |

右侧视角工具：复位视角、俯视布局、放大、缩小。

鼠标操作：左键旋转，右键平移，滚轮缩放。点击建筑会打开详情卡片，可以从卡片「靠近这栋建筑」。

## 目录结构

```
index.html        页面结构与 UI（标题卡、工具栏、建模说明）
style.css         样式
server.mjs        本地静态服务（Node 内置模块，无依赖）
src/
  layout.js       布局数据：红线、路网、高架匝道、河道、周边体量、塔楼与独栋
  textures.js     程序化贴图：立面、夜景自发光、路面、标识、光伏、水面
  world.js        根据布局数据生成三维场景（建筑、道路、树、车、路灯）
  main.js         渲染、相机、交互、导览、夜景、录制
tools/            开发辅助页面（截图、车辆轨迹检测、底图数字化叠加）
docs/             参考底图与航拍照片
```

## 建模依据

- **园区指标**：用地约 13.3 公顷（约 200 亩），总建筑面积约 48 万㎡，容积率 2.5，绿化率 15%。
- **建筑构成**：38 栋花园独栋（4–6 层），7 栋集中办公（17–25 层），2 栋配套，另有一座下沉式商业广场。
- **路网与轮廓**：园区红线、内部路网和建筑轮廓取自百度地图和高德卫星图。周边道路按百度 50m 比例尺矢量图逐段数字化，包括青洋路高架及其匝道、青洋北路、河海东路、创客路、虹阳路和沪蓉高速连接线。
- **体量与立面**：按视觉中国 2026-07 航拍照片重绘，照片编号为 VCG211673826950、1656866554、1656874856。
- **其他参考资料**：[前瞻产业园区库](https://y.qianzhan.com/yuanqu/item/443e393d6764b2d3.html)、[简和建筑设计方案](http://gen-design.cn/detail/21)、[常房网](http://www.czfdc.com/sjview.asp?id=2858)、[天宁区政府](https://www.cztn.gov.cn/html/cztn/2019/CNPOLQOF_0619/19762.html)。

本模型是示意性三维重建，不是测绘成果。层数、高度和不可见的立面都是估算。独栋的数量和排布根据资料和底图推算，单体细部由程序生成。
